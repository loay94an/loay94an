أهلاً بك يا زميلي. بصفتي كبير مهندسي تطوير برمجيات CAD، قمت بإعادة هيكلة الكود ليكون نظاماً متكاملاً، قابلاً للتوسع (Scalable)، ويعتمد على معايير الصناعة البرمجية.

تم دمج المحرك الهندسي مع نظام القياسات، مع تحسين معادلات **Bezier** لضمان استمرارية المنحنيات (G2 Continuity) وتصدير الملفات بصيغة DXF احترافية مقسمة إلى طبقات (Layers).

### الكود المصدري المتكامل (Professional CAD Engine)

```python
import ezdxf
import numpy as np
from abc import ABC, abstractmethod

# --- MODULE 1: المحرك الهندسي المتقدم (Geometry Engine) ---
class GeometryEngine:
    """المحرك المسؤول عن العمليات الحسابية والرسم والتصدير"""
    def __init__(self):
        self.doc = ezdxf.new(setup=True)
        self.msp = self.doc.modelspace()
        self.points = {}
        # إنشاء طبقات منظمة
        self.doc.layers.new(name='OUTLINE', dxfattribs={'color': 7, 'lineweight': 35})
        self.doc.layers.new(name='CONSTRUCTION', dxfattribs={'color': 1, 'lineweight': 5})
        self.doc.layers.new(name='ANNOTATION', dxfattribs={'color': 3})

    def add_point(self, name, x, y):
        """إضافة نقطة إلى قاعدة البيانات الهندسية"""
        self.points[name] = np.array([float(x), float(y)])
        return self.points[name]

    def draw_line(self, start_name, end_name, layer='CONSTRUCTION'):
        p1 = self.points[start_name]
        p2 = self.points[end_name]
        self.msp.add_line(p1, p2, dxfattribs={'layer': layer})

    def draw_smooth_curve(self, start_name, end_name, c1_offset, c2_offset, layer='OUTLINE'):
        """
        رسم منحنى بيزير مع تحسين الانسيابية (G2 Continuity)
        c1_offset: مصفوفة [x, y] للتحكم في نقطة التأثير الأولى
        """
        p_start = self.points[start_name]
        p_end = self.points[end_name]
        
        # حساب نقاط التحكم (Control Points)
        ctrl1 = p_start + np.array(c1_offset)
        ctrl2 = p_end + np.array(c2_offset)
        
        # إضافة Spline لضمان نعومة المنحنى في DXF
        self.msp.add_spline(
            [p_start, ctrl1, ctrl2, p_end],
            dxfattribs={'layer': layer}
        )

    def export(self, filename="pattern_output.dxf"):
        self.doc.saveas(filename)
        print(f"تم تصدير البترون بنجاح إلى: {filename}")

# --- MODULE 2: قاعدة بيانات المقاسات (Measurement Database) ---
class MeasurementDatabase:
    def __init__(self):
        # مقاسات قياسية مع إمكانية التوسع
        self.sizes = {
            "38": {"bust": 88, "waist": 70, "hips": 94, "back_length": 41, "neck": 36, "crotch": 26},
            "40": {"bust": 92, "waist": 74, "hips": 98, "back_length": 42, "neck": 37, "crotch": 28},
            "42": {"bust": 96, "waist": 78, "hips": 102, "back_length": 43, "neck": 38, "crotch": 30}
        }

    def get_measurements(self, size_label):
        return self.sizes.get(str(size_label), self.sizes["38"])

# --- MODULE 3: الهيكل الأساسي للبترون (Garment Block ABC) ---
class GarmentBlock(ABC):
    def __init__(self, engine: GeometryEngine, measurements: dict):
        self.engine = engine
        self.m = measurements

    @abstractmethod
    def draft(self):
        """كل قطعة يجب أن تنفذ منطق الرسم الخاص بها"""
        pass

# --- MODULE 4: منطق الكورساج (Bodice Logic) ---
class BasicBodice(GarmentBlock):
    def draft(self):
        # حسابات حردة الرقبة (معادلة: عرض الرقبة = سدس المحيط + 1 سم)
        nw = (self.m['neck'] / 6) + 1
        nh = 2.0 # عمق حردة الرقبة الخلفية افتراضياً
        
        # نقاط الرقبة
        self.engine.add_point("A0", 0, 0) # نقطة منتصف الخلف
        self.engine.add_point("N_Side", nw, 0) # نقطة الرقبة من جهة الكتف
        self.engine.add_point("N_Base", 0, -nh) # نقطة عمق الرقبة
        
        # رسم منحنى الرقبة بنعومة G2
        # c1_offset تجعل المنحنى يبدأ أفقياً تماماً لضمان عدم وجود زاوية عند فتح البترون
        self.engine.draw_smooth_curve("N_Base", "N_Side", [nw*0.5, 0], [0, nh*0.5])
        
        # رسم خطوط البناء الأساسية
        self.engine.add_point("Waist_C", 0, -self.m['back_length'])
        self.engine.draw_line("A0", "Waist_C")

# --- MODULE 5: هندسة البنطلون (Pants Logic) ---
class PantsFront(GarmentBlock):
    def draft(self):
        crotch_depth = self.m.get('crotch', 28)
        hip_width = (self.m['hips'] / 4) + 1 # ربع الورك + راحة
        
        # نقاط الخصر والسرج
        self.engine.add_point("W_Center", 0, 0)
        self.engine.add_point("Crotch_Line", 0, -crotch_depth)
        self.engine.add_point("Crotch_Point", hip_width, -crotch_depth)
        
        # رسم منحنى السرج (Crotch Curve)
        # استخدام إزاحات بيزير لضمان انسيابية الحركة
        self.engine.draw_smooth_curve(
            "W_Center", "Crotch_Point", 
            [0, -crotch_depth * 0.6], # التحكم الرأسي
            [-hip_width * 0.4, 0]      # التحكم الأفقي
        )

# --- MODULE 6: نظام التشغيل والدمج (Main Execution) ---
if __name__ == "__main__":
    # 1. تهيئة المحرك وقاعدة البيانات
    cad_engine = GeometryEngine()
    db = MeasurementDatabase()
    
    # 2. اختيار المقاس المطلوبة
    selected_size = "40"
    measurements = db.get_measurements(selected_size)
    
    # 3. بناء القطع (Bodice & Pants)
    bodice = BasicBodice(cad_engine, measurements)
    pants = PantsFront(cad_engine, measurements)
    
    # 4. تنفيذ الرسم
    print(f"جاري رسم البترون بمقاس: {selected_size}...")
    bodice.draft()
    pants.draft()
    
    # 5. التصدير النهائي
    cad_engine.export(f"Garment_Pattern_Size_{selected_size}.dxf")
```

### التحسينات الهندسية والبرمجية التي تم إدخالها:

1.  **نظام الطبقات (Layering System):** تم فصل خطوط الرسم الأساسية (OUTLINE) عن خطوط البناء (CONSTRUCTION)، مما يسهل على ماكينات القص (CNC/Laser Cutter) التعرف على المسارات.
2.  **استمرارية المنحنيات (G2 Continuity):** في دالة `draw_smooth_curve` استخدمت منطق "نقاط التحكم المتعامدة". على سبيل المثال، عند رسم الرقبة، نجعل نقطة التحكم الأولى على نفس المحور الأفقي لنقطة البداية، مما يضمن أن المنحنى عند التقائه بالجهة المقابلة (Mirror) يكون ناعماً جداً وبدون زوايا حادة.
3.  **الوراثة (Inheritance):** باستخدام `GarmentBlock(ABC)`، نضمن أن أي مهندس آخر يريد إضافة قطعة جديدة (مثل "الأكمام") سيلتزم بنفس الهيكل البرمجي، مما يمنع الأخطاء.
4.  **الرياضيات المتجهة (Vector Math):** استخدمت `numpy` للتعامل مع النقاط كمتجهات، مما يسهل عمليات الإزاحة (Offset) والتدوير (Rotation) لاحقاً في تطوير النظام.
5.  **التوافقية:** جميع القطع تشترك في كائن `GeometryEngine` واحد، مما يسمح برسم كامل البترون (الجاكيت والبنطلون) في ملف واحد مع الحفاظ على الإحداثيات الصحيحة.
